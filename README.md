# aut_driving

Autonomous driving programming workspace. The ROS 2 workspace and project files
are kept together in this repository.

## Clone

```bash
git clone https://github.com/RE2031/aut_driving.git
```

`race_stack/build/`, `race_stack/install/`, and `race_stack/log/` are generated
by the ROS build and are not stored in Git. Build from `race_stack` using the
workspace's normal ROS 2 build process.

## 팀 개발 환경 설정

컨테이너 설정, 빌드, 시뮬레이션 실행, Git 작업 흐름은 [SETUP.md](SETUP.md)를 보세요.
